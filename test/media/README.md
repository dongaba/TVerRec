# 自動比較の設定

PowerShell 7 の `conf/user_setting.ps1` に `$script:compareDuplicateVideos = $true` を追加すると、移動時の同名動画比較を有効化できます。初期値は false で、既存の移動動作を維持します。true の場合は異なる動画を強制上書きせず両方を残します。比較結果は `db/media-replacement` に保存します。ffmpeg / ffprobe が必要です。

# 近似メディア比較

`Compare-TVerRecMedia` は置換可否の補助判定であり、同じ作品・編集であることの証明ではありません。呼出側が全区分共通の排他ロックを取得し、置換前のファイルを必ず退避します。

全ファイル SHA-256 が一致する場合だけ exact とします。それ以外は通常動画一つ・音声一つを要求し、画像添付以外の複数映像、音声欠落、未知コーデック、avg/r FPS差が0.001を超えるもの、全体時間差0.05秒超、元動画の縦横寸法が既存より小さいものを拒否します。映像・音声それぞれのstream duration差とstart_time差も0.05秒以内、チャンネル数は一致が必要です。必要なstream情報が無い形式も保守的に拒否します。音声PCMのサンプル数も一致が必要です。例外・実行失敗・解析不足は `Equivalent=false` です。avg/r FPSの一致はVFRでないことの完全な証明にはなりません。

映像は全編を1fps・640×360・yuv420pに変換して SSIM を計測し、全フレーム平均0.995以上かつ最小0.98以上を要求します。fps=1は短い映像差を見逃します。ダウンサンプルは字幕・細部の差を見逃します。したがって必ず元ファイルを退避し、near を同一と表示しません。

音声は全編を16kHz・元と同じ1または2チャンネルの signed PCM16にデコードします。C#の二つの子プロセスから最大一秒分ずつ読み、累積量だけを保持します。SNRは `10 log10(sum(x*x) / sum((x-y)*(x-y)))`、相関は `sum((x-meanX)*(y-meanY)) / sqrt(sum((x-meanX)^2)*sum((y-meanY)^2))` です。全編SNR28dB以上または相関0.999以上に加えて、各一秒区間もSNR24dB以上または相関0.999以上を要求します。差がゼロの区間は許容しますが、全編無音・片側無音は拒否します。相関による判定は一定音量差を許容します。チャンネルを維持して比較しますが、16kHz化で高域差を見逃す限界があります。

デコーダthreads=1、filter threads=1、動画最大4時間、PCM最大230,400,000サンプル/チャンネル、SSIM統計最大64MiB、子プロセス標準出力・標準エラー各1MiB、デコード合計おおむね3600秒を上限とします。終了時は子プロセスを回収し、一時ディレクトリを削除します。ffmpeg自身のメモリをOSで強制制限するものではありません。時間上限はデコードに適用され、ファイルハッシュ・ファイルシステムの停止を強制キャンセルするものではありません。対象は指定された二ファイルだけです。

回帰: `pwsh -NoProfile -File test/media/verify-media-compare.ps1`。合成30秒の完全一致、再エンコード、別音声、映像編集、時間差、無音、デコーダ欠落を検査します。実媒体はこのテストで読みません。

ローカル統合では新しい更新日時の版を採用し、解像度を下げる場合は保留します。旧版は保存先カテゴリ直下の `.tverrec-replaced/<タイトル>/` に退避し、同名JSONに元のパス・SHA・比較結果を記録します。退避データは自動削除しません。比較は全区分で排他し、1回の移動処理につき最大1件。完全SHAをキーに成功または確定した映像/音声差だけをキャッシュし、デコーダ障害やtimeoutは再試行可能にします。細部差の可能性が残るため退避版を残します。

置換直後の外部書き込みにも備え、採用する原本の `.source-recovery` コピーも退避先に残します。旧版と原本コピーの両方の容量が必要です。記録の `status` は pending / committed / failed で、pending は中断の可能性があるため手動確認が必要です。比較上限はタイトル間の移動関数1回あたり1件です。

不一致が先頭に残っても後続を比較できるよう、対象ファイルをカーソルで巡回します。各タイトルの移動関数で最大1件のため、全体の所要時間は衝突タイトル数に比例し、最悪でタイトル数×約1時間かかります。全区分共通ロックは比較1件ごとに解放し、別区分が使用中ならその回は保留します。
